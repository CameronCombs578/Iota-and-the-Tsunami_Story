## Decisions

One of the most important decisions I made for the project was to make the site interactive.
This choice made the site distinct and more entertaining for the audience. I made this decision
based on my desire to create a type of site that I had never created before. I wanted to use this
project as a test of my ability to create more interactive sites that deliver messages.

Another decision was to use JavaScript as one of my tools in creating the project. I had very
little experience using the programming language and had second thoughts before using it for this
project. However, with my AI assistants’ support, I was able to use JavaScript to turn my site from
ordinary to interactive.

## What Worked

Many elements and sections in my project worked well. One of these included the character
imagery, the “About” page, and the interactive story. When I had decided to use the Paint app to create
the characters, I never expected to create the images I was able to. My expectations were
exceeded. They were friendly and easy to manage. The “About” page effectively summarizes the
project, making it a great page to visit after reading the home page. I originally had concerns about whether
the “About” page would be necessary. However, the page provides a great in-depth explanation of the site's content. These
sections of the project did not all begin with full confidence. Many of them had to be refined throughout
the creation process.

## What You Would Do Differently

If I could redo this whole project and act differently than I originally had, I would have created a more
structured plan for the project's development. This plan would have allowed me to accomplish my desired
sections, which would result in the project better meeting my expectations. When I was working on my
project, I was only making additions without a set goal, making my project feel incomplete. However, I was
able to use my last week of development to complete the loose ends for the site.

## What You Learned

Throughout this whole project, I have learned the importance of scheduling tasks and being creative.
I could have enjoyed my time better if I did not have to rush to complete the project at the end. Rushing
tends to result in lower-quality work, which should be avoided. However, I am glad that I chose to expand
my experience in creating sites by trying to create an interactive site. This leap was exciting and uncertain
all at the same time. With some expectations set and weeks given to finish it, I am very content with
the current project that I have.
